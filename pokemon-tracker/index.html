About this app

How to set up

Open this link: mentalllygone.github.io/Grok/pokemon-tracker

iPhone: Open in Safari → Share → Add to Home Screen.

Android: Open in Chrome → three-dot menu → Add to Home screen or Install app.

This makes it open like an app. You can also use it as a regular website, but data is less reliable that way. Always Export a backup.

This is a simple tool for casually tracking Pokémon items that are not in the big name apps. It is basically an Excel sheet that is easier to fill out on your phone.

Everything you enter is stored only on this phone. It is not saved online. The data normally stays as long as you keep using the app, but it can be lost if you clear browser data, the phone runs low on storage, or you do not open the app for a long time.

Use Export to save a copy of your collection. Use Import to bring it back after an update or on a new phone. This is the only reliable backup.

If someone shares their Excel file with you, tap Import and select it. You will be asked whether to add their items to yours or replace everything. Export your own data first so you do not lose it.

Photos are compressed so they fit in the export file. They are meant as a quick reference, not for judging condition. Use the Condition field for that.

Tap + Add Item to enter something. Tap My Collection to see, search, or edit what you have.
